# Índice de sesiones

## Alcance del registro

Una sesión registra una interacción real y autorizada, con participante declarado, asistente, identificador único y referencias verificables. El registro permite localizar el punto de seguimiento de una consulta anterior, con los límites de las fuentes que se observaron.

Este índice no reconstruye aperturas de Obsidian ni accesos a GitHub. Una fecha en Git, el usuario del sistema y la identidad configurada como autor de commits no sustituyen la declaración del participante.

## Sesiones registradas

No se incorporan sesiones reales en la creación de esta primera versión documental. No existe en este índice un acceso previo que pueda utilizarse para atribuir novedades a un participante.

La [[11_Colaboracion/05_Sesiones/Plantilla_sesion|plantilla de sesión]] es un formato reutilizable, no un registro de acceso. Los ejemplos didácticos de la guía y de las pruebas tampoco se contabilizan como sesiones.

## Uso del índice

1. Aplica el [procedimiento de interacción](../../../docs/skills/interaccion-sesiones/PROCEDIMIENTO.md) ante una solicitud real de inicio.
2. Confirma la identidad mediante declaración y comprueba la hora y zona disponibles. Informa los datos que no puedas verificar.
3. Crea un archivo nuevo con identificador único a partir de la plantilla. Comprueba que el nombre no exista; no sobrescribas otro registro.
4. Añade a este índice una referencia al nuevo registro cuando la creación y esa actualización estén autorizadas. Coordina la edición si hay cambios concurrentes.
5. Consulta registros anteriores del mismo participante para hallar la última referencia de seguimiento pertinente. Explica su alcance local, remoto o parcial; no ordenes registros sin hora conocida como si hubiera una secuencia temporal comprobada.
6. En una consulta aislada, no añadas accesos ni actualices el punto de seguimiento por el solo hecho de mostrar información. Persiste su cobertura únicamente dentro de un inicio o cierre real autorizado y separa esa cobertura del commit actual observado.
7. Al finalizar, actualiza exclusivamente la sesión identificada conforme al cierre autorizado. No crees un inicio retrospectivo para una sesión ausente.

La sesión debe referenciar las [[03_Bitacora/Indice|bitácoras]], [[05_Errores/Indice|errores]], [[06_Pendientes/Indice|pendientes]], comentarios o relevos que aporten evidencia. Esas fuentes conservan su función original y no deben duplicarse íntegramente.
