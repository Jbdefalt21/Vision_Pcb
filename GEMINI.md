# Contexto para Gemini CLI

Antes de actuar en este repositorio, lee y sigue `docs/REGLAS_COMPARTIDAS.md`, fuente principal de reglas, y consulta `cerebro/01_Proyecto/Contexto.md` y `cerebro/00_Inicio/Dashboard.md`.

Respeta la rama autorizada y el trabajo existente. No borres código sin autorización. Documenta decisiones y cambios; ejecuta las pruebas pertinentes y reporta solo comprobaciones realizadas.

Esta etapa prepara el entorno de colaboración. No implementes visión artificial sin una tarea explícita. Hay procedimientos Markdown compartidos de invocación manual; no hay Skills nativas instaladas en el proyecto ni compatibilidad automática entre proveedores verificada.

## Procedimientos compartidos de lectura manual

El [catálogo](docs/colaboracion/CATALOGO_PROCEDIMIENTOS.md) permite elegir desarrollo, pruebas, gestión o bitácora. Consulta los [adaptadores manuales](docs/colaboracion/ADAPTADORES_MANUALES.md) para límites y aceptación por cliente.

Consulta el [router de contexto](docs/colaboracion/ROUTER_CONTEXTO.md), sigue el [flujo de trabajo](docs/colaboracion/FLUJO_TRABAJO.md) y registra sesiones relevantes con el [procedimiento de bitácora](docs/skills/bitacora/PROCEDIMIENTO.md). `docs/REGLAS_COMPARTIDAS.md` conserva la autoridad central. Estas referencias no implican Skills nativas instaladas ni carga automática.
