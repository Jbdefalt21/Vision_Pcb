# Instrucciones de proyecto para Claude Code

Lee y sigue `docs/REGLAS_COMPARTIDAS.md`, fuente principal de reglas. Antes de editar, consulta `cerebro/01_Proyecto/Contexto.md` y `cerebro/00_Inicio/Dashboard.md`.

Respeta la rama autorizada y los cambios existentes. No borres código sin autorización. Documenta decisiones y cambios, ejecuta las pruebas pertinentes y no afirmes haber probado algo sin hacerlo.

La etapa inicial prepara la colaboración; la visión artificial requiere una tarea posterior explícita. No hay Skills configuradas ni compatibilidad automática entre proveedores.
