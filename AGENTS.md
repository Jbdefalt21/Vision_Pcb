# Instrucciones para Codex

Estas instrucciones se aplican al repositorio completo.

- Lee y sigue `docs/REGLAS_COMPARTIDAS.md`, fuente principal de reglas.
- Antes de editar, consulta `cerebro/01_Proyecto/Contexto.md` y `cerebro/00_Inicio/Dashboard.md`.
- Respeta la rama autorizada y los cambios existentes; no borres código sin autorización.
- Documenta decisiones y cambios, ejecuta las pruebas pertinentes y comunica únicamente comprobaciones realizadas.
- La etapa inicial prepara la colaboración; no implementes visión artificial sin una tarea que lo solicite.
- Hay procedimientos Markdown compartidos de invocación manual. No hay Skills nativas instaladas en el proyecto ni compatibilidad automática entre proveedores verificada.

## Procedimientos compartidos de lectura manual

El [catálogo](docs/colaboracion/CATALOGO_PROCEDIMIENTOS.md) permite elegir desarrollo, pruebas, gestión o bitácora. Consulta los [adaptadores manuales](docs/colaboracion/ADAPTADORES_MANUALES.md) para límites y aceptación por cliente.

Consulta el [router de contexto](docs/colaboracion/ROUTER_CONTEXTO.md), sigue el [flujo de trabajo](docs/colaboracion/FLUJO_TRABAJO.md) y registra sesiones relevantes con el [procedimiento de bitácora](docs/skills/bitacora/PROCEDIMIENTO.md). `docs/REGLAS_COMPARTIDAS.md` conserva la autoridad central. Estas referencias no implican Skills nativas instaladas ni carga automática.
